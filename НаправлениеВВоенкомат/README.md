# Направление в военкомат

Внешняя печатная форма для документов:
- `ПриемНаРаботу`
- `ПриемНаРаботуСписком` (отдельный файл на каждого сотрудника)

## Закладки макета
- `v8_ФИО` — ФИО в дательном падеже
- `v8_адрес_военкомата` — адрес военкомата из воинского учета
- `v8_тек_дата_плюс_тридня_рабочих` — дата документа + 3 рабочих дня
- `v8_тек_дата` — дата документа
- `v8_ФИО2` — ФИО сокращённо с инициалами (например, `Иванов И.И.`)

## Важно
Кеш в `Справочник.Файлы` не используется (обход ошибки RLS на `ПолучитьОбъект`).
Макет берётся через HTTP `GetMeket` с `MaketType = "Направление в военкомат"`.
